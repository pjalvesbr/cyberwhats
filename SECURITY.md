# Política de segurança

## Versões com suporte

Só a versão mais recente do CyberWhats recebe correções de segurança.
Baixe sempre a última em https://github.com/pjalvesbr/cyberwhats/releases

## Como avisar sobre uma falha

Não abra uma issue pública. Use o botão **Report a vulnerability** na aba
Security deste repositório.

Diga a versão do CyberWhats, o que acontece e como reproduzir. Respondo assim
que puder e aviso quando a correção sair.

O CyberWhats é um projeto não-oficial, sem afiliação com o WhatsApp/Meta.
Falhas no próprio WhatsApp devem ser informadas à Meta.
